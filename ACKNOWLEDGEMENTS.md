# Acknowledgement

We thank Xingyu Zhang for pointing out the Sex encoding issue in the distributed risk calculator, which led to the explicit per-model Sex mapping introduced in version 1.0.1.

## Further acknowledgement (26 November 2026)
We also thank Xingyu Zhang for drawing attention to the absolute-value transformation used in the original construction of the released index. Together with the Sex encoding point acknowledged above, this observation has been addressed in version 1.0.1, in which the signed Cox coefficients are used for the published index.
